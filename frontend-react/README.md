# Frontend - Admin Toko Baju

Ini adalah bagian antarmuka (Frontend) dari aplikasi Web CRUD Toko Baju. Dibuat menggunakan React, TypeScript, Vite, dan Tailwind CSS.

## Fitur
- Menampilkan daftar produk baju dari database.
- Menambah produk baru.
- Mengedit data produk.
- Menghapus produk (bisa satu per satu atau massal lewat checkbox).

1. Pastikan server backend sudah menyala.
2. Install dependencies:
